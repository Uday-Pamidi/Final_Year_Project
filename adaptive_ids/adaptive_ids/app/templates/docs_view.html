Comparative Paradigm: Conventional Static IDS vs Adaptive DICI Architecture

Structural comparison demonstrating architectural superiority over conventional signature and static ML systems

5 CRITICAL AXES
Evaluation Dimension Conventional Static ML-IDS Proposed Adaptive CTI-IDS (DICI)
Threat Detection Scope Degrades rapidly against zero-day variants and mutated payloads. High false negatives on unseen traffic distributions. Hybrid supervised (XGBoost) + unsupervised (Isolation Forest) flags known attacks and catches novel outlier anomalies.
CTI Integration Passive IP/domain blocklists easily evaded by rapid port hopping, fast-flux DNS, and cloud IP cycling. CTI Transfer Model correlates threat telemetry directly into validated ground-truth training vectors.
Model Lifecycle & Ops Fixed frozen weights; requires expensive offline batch re-labeling and manual retraining cycles. Online incremental boosting updates booster trees with historical replay memory to prevent catastrophic forgetting.

1. CTI Transfer Model Correlation

τ = 0.75

The CTI Transfer Model computes a normalized correlation score fusing external threat intelligence with observed network sightings:

Score = w₁ • CTI_Conf + w₂ • (ThreatScore / 100) + w₃ • TelemetryConsistency

Default weights: \(w_1 = 0.40, w_2 = 0.35, w_3 = 0.25\). Flows with \(\text{Score} \ge 0.75\) are certified as validated ground-truth vectors.

2. Kolmogorov-Smirnov & PSI Drift

p < 0.05

Measures supremum distance between empirical cumulative distributions of baseline and active sliding windows:

D = sup_x | F_baseline(x) - F_active(x) |
PSI = ∑ (Active_i - Base_i) • ln(Active_i / Base_i)

Drift is alerted when \(p\)-value \(< 0.05\) and \(D > 0.18\) or \(\text{PSI} \ge 0.25\) across standard feature vectors.

3. Hybrid Classification & Uncertainty Trigger

τ = 0.70

Uncertainty condition that activates automated IoC extraction and CTI query:

Requires_CTI = (max_c P(c | x) < τ) ∨ (IsolationForest(x) == -1)

Flows with classification confidence below \(\tau = 0.70\) or flagged as Isolation Forest spatial outliers are submitted for threat enrichment.

4. SHAP Shapley Additive Attribution

TreeExplainer

Instance-level attribution decomposing log-odds predictions into additive feature contributions:

g(z') = φ₀ + ∑_{i=1}^M φ_i • z'_i

Where \(\phi_i\) is the Shapley marginal attribution for feature \(i\), explaining its direction and magnitude toward the verdict.
